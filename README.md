# 2026 業務主管獎金試算 App

依《2026業務主管獎金試算表_最終版》公式製作的純前端網頁 App。

## GitHub Pages 部署
1. 將本資料夾內所有檔案上傳至 Repository 根目錄。
2. Repository → Settings → Pages。
3. Source 選 Deploy from a branch。
4. Branch 選 main，Folder 選 /(root)，按 Save。
5. 網址：https://patrick110675.github.io/bonus-calculator/

資料以瀏覽器 localStorage 儲存，可從設定頁匯出／匯入 JSON 備份。
